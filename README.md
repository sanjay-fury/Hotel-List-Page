WayNest 🏨

Where Comfort Meets Travel

WayNest is a responsive hotel discovery and management web application built using React.js.

Features

- View hotel listings and details
- Search hotels by name
- Filter by location and price
- Add, edit and delete hotels
- Upload and preview hotel images
- Pagination
- Interactive maps using Leaflet
- Data persistence using localStorage

Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Redux Toolkit
- React Router
- Leaflet

Installation

1. Clone the repository:

   git clone https://github.com/sanjay-fury/Hotel-List-Page.git


2. Navigate to the frontend folder:

   cd Hotel-List-Page/frontend


3. Install dependencies:

   npm install


4. Start the application:

   npm start
